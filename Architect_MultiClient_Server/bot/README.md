
## Add bot to your clan
 Link bot add vào clan riêng: https://mezon.ai/developers/bot/install/1975403474640179200
## Installation

```bash
$ yarn
```

Tạo .env và private-key.pem ; public-key.pem
khi tạo .env nhớ đưa id clan của chú vào
PORT=ttt
APPLICATION_TOKEN=ttt
CLAN_ID=ttt

## Running the app

```bash
# development
$ yarn start
```
