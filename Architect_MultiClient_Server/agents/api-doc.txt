API create và cancel là như nhau.
curl -X POST http://localhost:8000/api/create_dispatch \
  -H "Content-Type: application/json" \
  -d '{
    "account": {
      "appid": "aaa",
      "token": "bbb"
    },
    "room_name": "ccc"
  }'

  -H "Content-Type: application/json" \
  -d '{

    },

  }'
