# Log Metrics Reading and Analysis Guide

## Overview of Log Metrics

These log metrics are generated by the `_metrics_loop()` function in the `vosk_service.py` file (lines 642-694). This is real-time monitoring information for the STT Vosk Service, recorded every 5 seconds (or according to the `metrics_interval_sec` config).

## Detailed Component Analysis

### 1. **System Metrics** 📊

```python
# From code: vosk_service.py, lines 657-664
active_clients = sum(len(m) for m in self.worker_recognizers)
with self._accumulated_chunks_lock:
    accumulated_clients = len(self.accumulated_chunks)
    total_accumulated_chunks = sum(len(chunks) for chunks, _, _, _ in self.accumulated_chunks.values())
```

- **`workers=6`**: Total number of active worker threads
  - *Source*: `self.num_workers` (set from config)
  - *Meaning*: System has 6 worker threads to process audio in parallel

- **`active_recognizers=0`**: Number of active recognizers
  - *Source*: `sum(len(m) for m in self.worker_recognizers)`
  - *Meaning*: Currently no clients are connected/processing audio
  - *⚠️ Note*: If clients are streaming audio, this number will be > 0

- **`accumulated_chunks_clients=0`**: Number of clients with accumulating chunks
  - *Source*: `len(self.accumulated_chunks)`
  - *Meaning*: No clients have audio chunks waiting for processing

- **`total_chunks=0`**: Total number of accumulating chunks
  - *Source*: `sum(len(chunks) for chunks, _, _, _ in self.accumulated_chunks.values())`
  - *Meaning*: System has processed all audio chunks

1. **Empty Queue**: No backlog, system processing in time
2. **VAD 100%**: All audio chunks processed
3. **Chunk duration 50ms**: Standard for realtime processing

### ⚠️ **Needs Attention:**

## Using Metrics for Troubleshooting

### **High latency:**
- Check high `avg_wait_ms`
- Check `total_q` and `per_worker` queues

### **Memory leaks:**
- Check continuously increasing `accumulated_chunks_clients`
- Check `active_recognizers` not decreasing after disconnect

### **Performance bottleneck:**
- Check uneven worker distribution
- Check `processed` count per worker

These metrics are extremely useful for monitoring and troubleshooting realtime audio processing systems!
